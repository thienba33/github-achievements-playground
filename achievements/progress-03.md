# Tien trinh Pair Extraordinaire (3/8)

Huy hieu **Pair Extraordinaire** vinh danh nguoi dong tac gia voi nguoi khac khi merge pull request (dong trailer Co-authored-by trong commit).

Cac tier cua Pair Extraordinaire:
- Bronze (Dong): 10 pull request duoc merge co dong tac gia
- Silver (Bac): 24 pull request duoc merge co dong tac gia
- Gold (Vang): 48 pull request duoc merge co dong tac gia
- Platinum (Bach kim): 100 pull request duoc merge co dong tac gia

De dat duoc, commit trong PR can co dong "Co-authored-by: Ten <email>" ghi nhan cong lao cua nguoi cong tac.

File rieng cho Pair Extraordinaire, khong lien quan den BTG.
