# Tien trinh Pull Shark (1/8)

Huy hieu **Pull Shark** trao cho nguoi mo cac pull request duoc merge.

Cac tier cua Pull Shark:
- Bronze (Dong): 2 pull request duoc merge
- Silver (Bac): 16 pull request duoc merge
- Gold (Vang): 128 pull request duoc merge
- Platinum (Bach kim): 1024 pull request duoc merge

Moi pull request hop le duoc merge deu duoc tinh, du la tren repo cua minh hay repo nguoi khac.

PR nay la mot trong 8 PR duoc merge tren repo playground de tien toi tier Bronze.

File rieng cho Pull Shark, khong lien quan den BTG.
